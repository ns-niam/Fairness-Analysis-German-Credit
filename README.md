# Fairness Analysis on German Credit Dataset

## Objective
This project analyzes fairness in machine learning models used for credit scoring.

## Features Analyzed
- Sensitive: Sex, Age
- Proxy: Job, Housing, Savings

## Model
Random Forest Classifier

## Metrics
- Accuracy
- Recall
- Precision
- F1 Score
- Demographic Parity
- Equal Opportunity

## Key Findings
- Model performance differs across groups
- Proxy features reveal hidden bias
- Fairness is critical in real-world ML systems# Fairness-Analysis-German-Credit
